# Tic-Tac-Toe (Python CLI Game)

A 2-player console-based implementation of the classic **Tic-Tac-Toe** game built using pure Python 3. This project demonstrates core programming fundamentals including input validation, loops, functions, lists, conditional statements, and exception handling without relying on external libraries.

---

## 🎮 Features

- **2-Player Gameplay:** Take turns with a friend on the same keyboard (`Player 1: X`, `Player 2: O`).
- **Dynamic 3x3 Grid Display:** Clean, formatted CLI grid that updates after every move.
- **Comprehensive Input Validation:** Handles non-numeric inputs, empty inputs, out-of-range choices (less than 1 or greater than 9), and already occupied cells gracefully without crashing.
- **Win & Draw Detection:** Automatically checks all 8 winning combinations (rows, columns, diagonals) and detects draws when all 9 cells are full.
- **Play Again Feature:** Prompts players at the end of each round to start a new game or exit.
